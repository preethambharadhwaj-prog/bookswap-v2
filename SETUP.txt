BOOKSHELF (BookSwap) - complete Django project

1. Unzip, open the bookshelf folder in VS Code (the folder that contains manage.py).
2. Terminal:
     python -m venv env
     .\env\Scripts\Activate.ps1
     pip install -r requirements.txt
     python manage.py makemigrations bookswap
     python manage.py migrate
     python manage.py test            (should end with OK)
     python manage.py seed_demo       (optional demo users, password demo12345)
     python manage.py createsuperuser
     python manage.py runserver       -> http://127.0.0.1:8000/
3. GitHub:
     git init && git add . && git commit -m "BookSwap"
     git branch -M main
     git remote add origin https://github.com/YOUR-USERNAME/bookswap.git
     git push -u origin main
   (commit the bookswap/migrations/0001_initial.py file that makemigrations creates)
4. Render: build command
     pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate
   start command:  gunicorn bookshelf.wsgi
   env vars: DATABASE_URL (internal URL), SECRET_KEY, DEBUG=0, PYTHON_VERSION=3.12.3

NOTE: if you already have a bookshelf project with migrations 0001/0002, do NOT overwrite its
bookswap/migrations folder; copy over everything else and run makemigrations.
